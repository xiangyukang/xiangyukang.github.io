## Publishing

Create a public repository named `xiangyukang.github.io` under the `xiangyukang` account. Upload `index.html`, `.nojekyll`, and this README at its root. Under **Settings → Pages**, choose **Deploy from a branch**, **main**, and **/(root)**, then save. Wait for deployment before using the URL.

## Editing

The entire site lives in `index.html`, with system fonts, embedded CSS, and inline SVG. No build tools or third-party scripts are required. Keep the visible profile, metadata, and JSON-LD consistent when updating personal details. The empty `.nojekyll` file disables Jekyll.
